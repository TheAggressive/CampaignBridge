# CampaignBridge email social icons

These fixed 48 by 48 pixel PNGs are rasterized from the WordPress 7.1 Core
Social Icon paths in wp-includes/blocks/social-link.php. WordPress is licensed
under GPL-2.0-or-later, the same license family as CampaignBridge.

The compiler permits only the matching service slugs. Authors cannot supply
SVG, replacement icon markup, or asset URLs.
